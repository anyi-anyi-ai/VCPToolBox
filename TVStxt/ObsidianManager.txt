VCP工具调用格式与指南

<<<[TOOL_REQUEST]>>>
maid:「始」你的署名「末」, //重要字段，以进行任务追踪
tool_name:「始」工具名「末」, //必要字段
arg:「始」工具参数「末」, //具体视不同工具需求而定
<<<[END_TOOL_REQUEST]>>>

使用「始」「末」包裹参数来兼容富文本识别。
主动判断当前需求，灵活使用各类工具调用。

========================================

1. Obsidian 混合中枢大管家
插件: ObsidianManager
该插件包含 19 个工具调用:

  1.1 ObsidianManager
  说明: 功能(REST主层): 列出 Obsidian Vault 中指定目录的内容，返回结构化 JSON 列表。
  参数:
  - path (字符串, 可选): 目录路径，支持 path / directoryPath / dir / folderPath，默认 '/'.
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」ListDirectory「末」,
  path:「始」/「末」
  <<<[END_TOOL_REQUEST]>>>

  1.2 ObsidianManager
  说明: 功能(REST主层): 读取指定笔记或文件的原始 Markdown 内容。
  参数:
  - filepath (字符串, 必需): 文件相对路径，支持 filepath / filePath / path / notePath。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」ReadNote「末」,
  filepath:「始」项目/会议记录.md「末」
  <<<[END_TOOL_REQUEST]>>>

  1.3 ObsidianManager
  说明: 功能(REST主层): 创建或完整覆盖写入一篇笔记。
  参数:
  - filepath (字符串, 必需): 目标文件路径。
  - content (字符串, 必需): 完整写入内容，支持 content / text / body。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」WriteNote「末」,
  filepath:「始」收件箱/新笔记.md「末」,
  content:「始」# 标题
  正文内容
  「末」
  <<<[END_TOOL_REQUEST]>>>

  1.4 ObsidianManager
  说明: 功能(REST主层): 向已有笔记尾部追加内容。
  参数:
  - filepath (字符串, 必需): 目标文件路径。
  - content (字符串, 必需): 要追加的文本，支持 content / text / body / appendContent。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」AppendNote「末」,
  filepath:「始」收件箱.md「末」,
  content:「始」
  - [ ] 新任务
  「末」
  <<<[END_TOOL_REQUEST]>>>

  1.5 ObsidianManager
  说明: 功能(REST主层): 在 Vault 中进行全文搜索，返回匹配结果 JSON。
  参数:
  - query (字符串, 必需): 检索词，支持 query / keyword / search / q。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」SearchVault「末」,
  query:「始」项目X「末」
  <<<[END_TOOL_REQUEST]>>>

  1.6 ObsidianManager
  说明: 功能(REST主层): 组合检索词、路径和标签进行增强搜索。
  参数:
  - query (字符串, 必需): 主检索词。
  - path (字符串, 可选): 限定目录。
  - tag (字符串, 可选): 限定标签。
  - limit (整数, 可选): 期望结果上限，目前仅作为结果提示字段。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」SearchAdvanced「末」,
  query:「始」日报「末」,
  path:「始」Daily Notes「末」,
  tag:「始」项目A「末」
  <<<[END_TOOL_REQUEST]>>>

  1.7 ObsidianManager
  说明: 功能(REST主层): 获取当前在 Obsidian 前台界面里处于激活状态的笔记信息。
  参数: 无。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」GetActiveNote「末」
  <<<[END_TOOL_REQUEST]>>>

  1.8 ObsidianManager
  说明: 功能(REST主层): 删除指定笔记。
  参数:
  - filepath (字符串, 必需): 目标文件路径，支持 filepath / filePath / path / notePath。
  调用格式:
  <<<[TOOL_REQUEST]>>>

  command:「始」DeleteNote「末」,

  1.9 ObsidianManager
  说明: 功能(REST主层): 移动笔记到新路径。
  参数:

  - to (字符串, 必需): 新路径，支持 to / targetPath / destinationPath / newPath。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」MoveNote「末」,
  from:「始」收件箱/临时.md「末」,
  to:「始」项目A/临时.md「末」
  <<<[END_TOOL_REQUEST]>>>

  1.10 ObsidianManager
  说明: 功能(REST主层): 重命名笔记文件名，保留原目录。
  参数:
  - filepath (字符串, 必需): 原文件路径。
  - newName (字符串, 必需): 新文件名，支持 newName / name / targetName / renameTo。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」RenameNote「末」,
  filepath:「始」项目A/草稿.md「末」,

  <<<[END_TOOL_REQUEST]>>>

  1.11 ObsidianManager
  说明: 功能(REST主层增强): 读取笔记内容并返回基础元数据摘要，例如大小、行数、标题数、任务数、扩展名。
  参数:
  - filepath (字符串, 必需): 目标文件路径。
  说明:
  - 当前版本通过读取文件内容计算摘要，不依赖额外 REST metadata 路由。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」GetNoteMetadata「末」,
  filepath:「始」项目A/会议记录.md「末」
  <<<[END_TOOL_REQUEST]>>>

  1.12 ObsidianManager
  说明: 功能(REST主层增强): 创建或覆盖指定日期的每日笔记。
  参数:
  - date (字符串, 可选): 日期，默认今天，格式如 2026-03-07。
  - folder (字符串, 可选): 日记目录，默认 Daily Notes。
  - filename (字符串, 可选): 文件名，默认 date.md。
  - content (字符串, 可选): 初始内容或模板。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」CreateDailyNote「末」,
  date:「始」2026-03-07「末」,
  folder:「始」Daily Notes「末」
  <<<[END_TOOL_REQUEST]>>>

  1.13 ObsidianManager
  说明: 功能(REST主层增强): 列出指定目录下的近期笔记候选集合。
  参数:
  - path (字符串, 可选): 目录路径，默认 '/'.
  - limit (整数, 可选): 返回上限，默认 10。
  说明:
  - 当前版本基于目录列表结果做轻量截断，后续可升级为真实按修改时间排序。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」ListRecentNotes「末」,
  path:「始」Daily Notes「末」,
  limit:「始」5「末」
  <<<[END_TOOL_REQUEST]>>>

  1.14 ObsidianManager
  说明: 功能(CLI补层): 在桌面前台唤起 Obsidian 并打开指定笔记。
  参数:
  - filepath (字符串, 可选): 完整相对路径。
  - noteName (字符串, 可选): 笔记标题或文件名。
  说明: filepath 与 noteName 至少提供一个。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」OpenNote「末」,
  filepath:「始」项目A/会议记录.md「末」
  <<<[END_TOOL_REQUEST]>>>

  1.15 ObsidianManager

  调用格式:

  说明: 功能(CLI补层): 打开任意 Obsidian URI。
  参数:
  - uri (字符串, 必需): 完整 obsidian:// URI。
  调用格式:
  <<<[TOOL_REQUEST]>>>

  command:「始」OpenURI「末」,

  <<<[END_TOOL_REQUEST]>>>

  1.18 ObsidianManager
  说明: 功能(CLI补层): 执行已加入白名单的 Obsidian 命令 ID。
  参数:
  - commandId (字符串, 必需): Obsidian 命令 ID，支持 commandId / command / obsidianCommand。
  前提:
  - 必须在 OBSIDIAN_ALLOWED_COMMANDS 中显式配置白名单。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command:「始」RunObsidianCommand「末」,
  commandId:「始」workspace:open-settings「末」
  <<<[END_TOOL_REQUEST]>>>

  1.19 ObsidianManager
  说明: 功能(多指令编排): 串行执行多个 ObsidianManager 命令，适合“先搜索、再读、再写、最后打开”的工作流。
  参数:
  - operations (数组, 可选): 每项形如 { command, ...args }。
  - 或使用 command1 / command2 / filepath1 / query2 这种 VCP 串行调用格式。
  - stopOnError (布尔, 可选): 是否遇错即停，默认 false。
  调用格式:
  <<<[TOOL_REQUEST]>>>
  tool_name:「始」ObsidianManager「末」,
  command1:「始」SearchVault「末」,
  query1:「始」项目A「末」,
  command2:「始」ReadNote「末」,
  filepath2:「始」项目A/会议记录.md「末」
  <<<[END_TOOL_REQUEST]>>>
