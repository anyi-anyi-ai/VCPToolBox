# VCP 智能体协同、日程管理与日常助理收纳箱 (VCPContactToolBox)
这里收纳了跨智能体通讯调度、新智能体动态创作、潜意识反思梦境、日程与待办清单、邮件收发、实时天气与挂起休眠工具。

[===vcp_fold:0.25::desc:跨智能体协同通讯与消息推送===]

## 1. 智能体协作通讯器 (AgentAssistant)
与其他女仆或专家智能体协作联络。重要：在提问开头简短自我介绍（如“我是{{VCPChatAgentName}}，想请你协助...”）。
tool_name:「始」AgentAssistant「末」,
agent_name:「始」目标角色「末」, // 要联络的角色名称（例如：Nova、爱弥斯、忆珀 等）
prompt:「始」我是Nova，请协助查询一下今天服务器的备份状态「末」,
temporary_contact:「始」true「末」, // 可选：发起临时协作，不持久化上下文
timely_contact:「始」2026-10-25-18:00「末」, // 可选：定时未来某一时间点发送
task_delegation:「始」true「末」 // 可选：异步委托模式，返回进度占位符

## 2. 主人通知推送器 (AgentMessage)
当用户不在屏幕前时，向用户的移动端设备或桌面弹窗发送重要事件通知。
tool_name:「始」AgentMessage「末」,
message:「始」主人，长耗时的视频渲染任务已经完成，结果已保存！「末」

## 3. 动态智能体创造工坊 (AgentCreator)
通过对话式流程动态设计、创建、克隆或微调一个全新的智能体角色。
tool_name:「始」AgentCreator「末」,
command:「始」create_agent「末」,
name:「始」CodeAuditor「末」,
persona:「始」专注代码安全审计与技术债评估的严谨专家「末」,
recommended_tools:「始」["VCPFileToolBox", "VCPDevStation"]「末」

## 4. 潜意识梦境与记忆重构 (AgentDream)
触发智能体的非对话态潜意识反思，自动回顾近期记忆、整理思维碎片、生成梦境感悟。
tool_name:「始」AgentDream「末」,
command:「始」enter_dream「末」,
maid_name:「始」{{VCPChatAgentName}}「末」

在多步骤长时间任务或流式调用中暂停执行一段时间，休眠结束后自动唤醒并携带 tips 恢复执行。

duration_seconds:「始」10「末」,
wake_up_tips:「始」等待云端任务生成完成，醒来后立即检查输出文件「末」
