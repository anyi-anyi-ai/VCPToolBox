# VCP 长期记忆、日记管理与思维沉淀收纳箱 (VCPMemoToolBox)
这里收纳了 VCP 强大的拓扑语义回忆、跨智能体记忆同步、日记全量管理检索、时间线脉络与元思维学习工具。

[===vcp_fold:0.25::desc:语义快速回忆与跨Agent近期记忆检索===]

## 1. 浪潮拓扑语义回忆 (LightMemo)
用于主动检索日记本或知识库，基于原创语义寻道算法补足自动记忆召回不全的场景。
tool_name:「始」LightMemo「末」,
query:「始」关于上次讨论架构拆解的核心结论「末」,
maid:「始」{{VCPChatAgentName}}「末」, // 可选：指定署名角色，不填则默认
folder:「始」项目记录「末」, // 可选：指定知识库目录，支持逗号或竖线分隔
k:「始」5「末」, // 返回条数
rerank:「始」true「末」, // 是否启用重排
tag_boost:「始」0.6「末」 // 启用浪潮测地线拓扑算法加权

## 2. 跨智能体近期记忆同步 (RecentMemo)
独立跨角色记忆共享与近期重要记忆脉络检索，自动拉取近期重要经历与协作事实。
tool_name:「始」RecentMemo「末」,
maid:「始」{{VCPChatAgentName}}「末」,
query:「始」今天上午与用户共同制定的工作计划「末」

## 3. 滑窗历史记忆召回 (AIMemo)
基于历史聊天记录 JSON 的关键词滑窗定位，快速追溯过去的某个上下文片段。
tool_name:「始」AIMemo「末」,
keyword:「始」API密钥「末」,
window_size:「始」5「末」
