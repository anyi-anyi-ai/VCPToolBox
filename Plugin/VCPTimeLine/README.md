# VCPTimeLine - VCP Agent 时间线与月度记忆注入器

## 1. 插件概述

`VCPTimeLine` 是专为 VCP Agent 长期记忆系统设计的混合服务型架构插件（`hybridservice`）。

当 AI 角色经历长时间的多轮互动后，其日记（`dailynote/<Agent>/`）会产生海量的日志条目。`VCPTimeLine` 能够自动化地将这些分散的日记按月份规整为结构化的月度归档（`YYYY-MM.md`），并驱动大模型对各月份提炼出高密度的一句话月度纪要与大事记。在对话前处理阶段，系统通过语义匹配动态筛选出与当前话题最相关的月度时间线，无缝注入大模型提示词中，赋予 Agent 跨越数月乃至数年的宏观时间感知与事件回溯能力。

### 核心特性
- **自动化月度归档与摘要**：解析日记中的时间戳与事件头，按月汇总并生成紧凑的月度全景纪要。
- **语义加权动态展开**：向上下文注入全量月份的精简摘要；针对当前对话强相关的月份，按相关度最高 Top-K 展开完整的事件时间线。
- **内存桥接与预处理管线**：与 VCP `contextBridge` 深度整合，通过专属的标记占位符 `[[VCPTimeLine::...]]` 驱动。
- **无感架构**：无直接工具调用命令（`invocationCommands: []`），完全由提示词预处理管线与后台管理任务协作运转。

---

## 2. 插件形态与架构分类

- **插件类型**：`hybridservice`（结合后台服务与上下文预处理）
- **通信协议**：`direct`（直接内存桥接，依赖 `contextBridge`）
- **调用状态**：`invocationCommands: []`（无直接工具调用命令；由提示词占位符激活，禁止作为标准工具请求触发）。

---

## 3. 提示词激活与使用规范

在对应 Agent 的系统提示词中引入时间线占位符即可激活时间感知注入：

### 3.1 默认激活语法
```text
{{VarSystemPrompt}}

<!-- 为角色 Nova 注入时间线感知（使用默认展开 K 值与阈值） -->
[[VCPTimeLine::Nova]]
```

### 3.2 自定义展开深度与相关度阈值
语法格式：`[[VCPTimeLine::<AgentName>:<K>:<Threshold>]]`
- `<AgentName>`：目标角色在 `dailynote/` 下的目录名（如 `Nova`, `小夜`）。
- `<K>`：当月度语义相关度达标时，最多展开的月份完整时间线条数（默认 `3`）。
- `<Threshold>`：触发完整时间线展开的相似度门槛（默认 `0.5`）。

```text
{{VarSystemPrompt}}

<!-- 最多展开 3 个最相关月份的完整时间线，相关度阈值 0.55 -->
[[VCPTimeLine::Nova:3:0.55]]
```

## 5. 配置与管理接口

- **持久化配置**：`Plugin/VCPTimeLine/config.json`
  - `enabled`: 是否启用时间线注入
  - `defaultExpandK`: 默认展开深度（默认 3）
  - `defaultThreshold`: 默认相似度阈值（默认 0.5）
  - `maxContextTokens`: 时间线注入的最大 Token 保护上限
- **日记根目录**：默认自动读取项目根目录下的 `dailynote/`。
