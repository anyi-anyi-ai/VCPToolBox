# VCPComfyUIPlugin 多类型提示词支持

## 概述

VCPComfyUIPlugin 现已支持基于节点标题的多类型提示词识别，允许更精确地控制复杂工作流中的不同提示词节点。

## 支持的提示词类型

| 提示词类型 | 参数名 | 节点标题模式 | 说明 |
|-----------|--------|-------------|------|
| 主要文生图提示词 | `prompt` | `text_image_prompt` | 主要的图像生成提示词 |
| 负面提示词 | `negative_prompt` | `negative_prompt` | 负面提示词 |
| 面部修复提示词 | `face_prompt` | `face_image_prompt` | 面部细节优化提示词 |
| 手部修复提示词 | `hand_prompt` | `hand_image_prompt` | 手部细节优化提示词 |
| 放大图片提示词 | `enlarge_prompt` | `enlarge_image_prompt` | 图像放大时的提示词 |
| 风格提示词 | `style_prompt` | `up-prompt` | 风格控制提示词 |

## 使用方法

### 1. 基础用法

```json
{
  "prompt": "美丽的女孩，长发，微笑",
  "negative_prompt": "ugly, deformed, bad anatomy"
}
```

### 2. 高级用法（多提示词类型）

```json
{
  "prompt": "美丽的女孩，长发，微笑",
  "negative_prompt": "ugly, deformed, bad anatomy",
  "face_prompt": "perfect face, detailed eyes, beautiful smile",
  "hand_prompt": "detailed hands, perfect fingers",
  "enlarge_prompt": "high quality, detailed, 4k",
  "style_prompt": "anime style, vibrant colors"
}
```

### 3. 工作流节点设置

在工作流JSON文件中，确保CLIPTextEncode节点的`_meta.title`包含相应的关键词：

```json
{
  "2": {
    "inputs": {
      "text": "{prompt}",
      "clip": ["1", 1]
    },
    "class_type": "CLIPTextEncode",
    "_meta": {
      "title": "text_image_prompt"
    }
  },
  "4": {
    "inputs": {
      "text": "{face_prompt}",
      "clip": ["1", 1]
    },
    "class_type": "CLIPTextEncode",
    "_meta": {
      "title": "face_image_prompt"
    }
  }
}
```

## 占位符支持

工作流中的提示词节点可以使用占位符格式，系统会自动替换：

- `{prompt}` -> 主要提示词内容
- `{negative_prompt}` -> 负面提示词内容
- `{face_prompt}` -> 面部修复提示词内容
- `{hand_prompt}` -> 手部修复提示词内容
- `{enlarge_prompt}` -> 放大图片提示词内容
- `{style_prompt}` -> 风格提示词内容

## API命令

### 获取支持的提示词类型

```bash
echo '{"command": "get_prompt_types"}' | python main.py
```

### 生成包含多种提示词的图像

```bash
echo '{
  "command": "generate_image",
  "workflow_id": "test_prompts.json",
  "prompt": "美丽的女孩",
  "negative_prompt": "ugly, bad anatomy",
  "face_prompt": "perfect face, detailed eyes",
  "hand_prompt": "perfect hands",
  "enlarge_prompt": "high quality, 4k"
}' | python main.py
```

## 兼容性

- 向后兼容现有的简单提示词工作流
- 支持传统基于内容识别的负面提示词检测
- 自动回退到基础模式当无法识别节点类型时

## 调试信息

系统会在调试日志中输出更新的节点信息：

```
[VCPComfyUIPlugin] Updated prompt nodes: ['2', '4', '5'] with params: ['prompt', 'face_prompt', 'hand_prompt']
```

## 注意事项

1. 节点标题匹配是大小写不敏感的
2. 一个工作流可以有多个相同类型的提示词节点
3. 如果同时提供了直接参数和占位符，直接参数优先
4. 系统会自动为创建的基础工作流添加适当的节点标题
