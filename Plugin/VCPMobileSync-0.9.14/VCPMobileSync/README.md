# VCPMobileSync

**让 VCPChat 桌面端和 VCPMobile 手机端的数据保持同步。**

装了这个插件，你在电脑上创建的 AI 智能体、聊天话题、历史消息，可以一键同步到手机上；反过来，在手机上聊的内容、新建的对话，也能同步回电脑。两端数据保持一致，换设备使用不中断。

---

## 这个插件能同步什么？

| 数据类型 | 说明 |
|---------|------|
| **智能体（Agent）** | 名字、系统提示词、模型设置等 |
| **群组（Group）** | 群成员、群模式、群提示词等 |
| **话题（Topic）** | 每个智能体/群组下的对话话题 |
| **消息历史** | 聊天记录、AI 回复内容 |
| **附件** | 聊天中发送的图片、文件等 |
| **头像** | 智能体和群组的自定义头像 |

**同步是双向的**：无论在电脑端还是手机端修改，都会同步到另一端。如果两边都有新内容，插件会自动合并，不会丢数据。

## 安装依赖

在 VCPChat **根目录**下执行：

```bash
# 安装数据库依赖
pnpm install better-sqlite3

# 重新编译原生扩展（必须步骤，否则插件启动会报错）
pnpm exec electron-rebuild --only better-sqlite3
```

## 配置插件

1. 复制配置模板：

```bash
cp config.env.example config.env
```

2. 编辑 `config.env`，至少填写以下两项：

```env
# 【必填】同步密码。手机端连接时必须输入这个密码，建议设复杂一点
MobileSyncToken=your_super_secret_token_here

# 【必填】同步服务端口，默认 5975，一般不用改
MobileSyncPort=5975
```

> 💡 **Mobile Sync Token 是什么？** 就像 WiFi 密码一样，防止陌生人连上你的同步服务。电脑和手机两边的 Token 必须完全一致才能同步。

## 手机端配置

打开 VCPMobile 手机端 → 设置 → 同步设置，你会看到三个输入框：

| 手机端显示的名称 | 示例值 | 说明 |
|----------------|--------|------|
| **HTTP 服务 URL** | `http://192.168.1.100:5974` | 桌面端分布式服务器的地址 |
| **WebSocket 服务 URL** | `ws://192.168.1.100:5975` | 本插件的同步地址（注意端口是 5975） |
| **Mobile Sync Token** | `your_super_secret_token_here` | 和上面 `config.env` 里设的密码一致 |

> ⚠️ 电脑和手机必须在**同一个局域网**（同一个 WiFi）下才能同步。`192.168.1.100` 要换成你电脑的实际局域网 IP。

## 如何使用

### 首次同步

> **更新插件时，务必删除旧的 sync_state.db 索引数据库**

1. **开启桌面端分布式服务器**
   - 打开 VCPChat 桌面端 → 全局设置 → 高级功能→ 开启「VCP分布式服务器」→ __**重启客户端**__

2. **等待插件就绪**
   - 插件会自动加载，扫描本地数据建立索引
   - 索引完成后，日志中会出现 `WebSocket 同步总线已启动`
   - 数据多的话可能需要 1~3 秒，请稍等

3. **手机端发起同步**
   - 打开手机端 VCPMobile → 设置 → 同步设置 → 点击「立即同步」
   - 首次同步会传输全量数据，可能需要几分钟，取决于消息数量
   - 后续同步只传变化的内容，通常几秒完成

4. **同步完成**
   - 手机端会显示同步进度和结果
   - 现在两端的智能体、话题、消息就一致了

### 日常使用中需要手动同步吗？

需要。只要桌面端开着，手机端会自动保持同步。你也可以在设置里随时手动点「立即同步」。

## 常见问题 Q&A

### 基础问题

**Q: 这个插件是干嘛的？**
> 简单说：让你电脑上的 VCPChat 和手机上的 VCPMobile 数据保持一致。在电脑上聊的 AI，手机上也能接着聊。

**Q: 同步会不会覆盖我的数据？**
> 不会。同步采用增量合并策略，两边的新内容都会保留。如果同一条消息两边都有修改，会以时间戳较新的为准。

**Q: 同步需要联网吗？**
> 不需要连接互联网。只要电脑和手机连在同一个 WiFi（局域网）里就能同步。数据不会上传到任何第三方服务器，全程本地传输。

**Q: 同步过程中可以正常聊天吗？**
> 不可以。但是同步速度很快，只需要十几秒，不影响你正常使用。

**Q: 桌面端关闭了，手机端还能用吗？**
> 可以正常使用，但无法同步。桌面端是同步的"服务端"，关了之后手机端只能操作本地数据。

### 数据范围

**Q: 附件（图片、文件）能同步吗？**
> 能。聊天中发送的图片、文档等附件都会同步到另一端。大文件可能需要稍久一点（暂时不支持同步桌面端附件，太多了）。

**Q: 删除的智能体/消息会同步吗？**
> 会。在一端删除的内容，同步后另一端也会删除。删除操作有软保护机制，短期内可以恢复。

**Q: 智能体的系统提示词、模型设置会同步吗？**
> 会。智能体的名称、系统提示词、温度、模型选择等配置都会同步。

**Q: 群组里的成员列表会同步吗？**
> 会。群组的成员、群模式、群提示词等配置都会同步。

### 连接问题

**Q: 手机端连不上桌面端怎么办？**
> 按顺序检查：
> 1. 桌面端「分布式服务器」是否已开启？
> 2. 插件索引扫描是否完成？（看日志有没有出现 `WebSocket 同步总线已启动`）
> 3. 手机和电脑是否连在同一个 WiFi/局域网/IP？
> 4. 手机端填写的 IP 地址是不是电脑的实际局域网 IP？（可以在电脑命令行输入 `ipconfig` 查看）
> 5. `config.env` 里的 `MobileSyncToken` 和手机端填的是否完全一致？
> 6. 防火墙是否拦截了 5975 端口？

**Q: 为什么首次同步很慢？**
> 首次同步需要把全部消息历史、附件、配置都传一遍。消息越多越慢，这是正常的。后续同步只传变化的内容，速度会快很多。

**Q: 手机和电脑不在同一个 WiFi 能同步吗？**
> 目前不支持。必须在同一个局域网内。如果你需要跨网络同步，可以通过 VPN 或内网穿透工具让手机连入电脑所在的网络。

**Q: 可以同时连多台手机吗？**
> 技术上支持，但不建议。多台手机同时修改同一数据可能产生冲突。推荐一次只连一台手机。

### 异常与排查

**Q: 同步卡在某个阶段不动了怎么办？**
> 1. 查看桌面端日志，看有没有报错
> 2. 检查 WebSocket 连接是否断开（日志中会有 `disconnection`）
> 3. 尝试在手机端取消同步，重新发起一次
> 4. 如果一直卡住，重启桌面端客户端通常能解决

**Q: 消息同步缺失（手机上少了某些消息）怎么办？**
> 1. 在手机端手动点一次「立即同步」
> 2. 检查桌面端日志中 `SYNC_MESSAGE_DIFF_BATCH` 阶段的记录
> 3. 如果某话题的消息两边差异很大，插件可能会跳过该话题以避免误判，此时可以删除手机端该话题后重新同步

**Q: 上传实体（智能体/群组）失败怎么办？**
> 常见原因：
> - `Config ID mismatch`：群组配置的 ID 和请求不一致
> - `corrupted config`：桌面端本地配置文件损坏，插件拒绝覆盖以防止数据丢失
> - `Parent entity not found`：话题的父级智能体/群组在桌面端不存在
>
> 解决方法：先在桌面端确认该实体存在且配置正常，然后重新同步。

**Q: 桌面端日志在哪里看？**
> 日志文件保存在插件目录下：
> ```
> VCPMobileSync/logs/sync/sync_xxxxxxxx.log
> ```
> 用记事本打开即可查看。日志是实时写入的，可以开着日志文件刷新看最新内容。

### 其他

**Q: Token 泄露了怎么办？**
> 修改 `config.env` 里的 `MobileSyncToken`，重启桌面端，同时在手机端更新 Token。

**Q: 换了新电脑/重装了系统怎么办？**
> 1. 在新电脑上安装 VCPChat 和本插件
> 2. 配置相同的 `MobileSyncToken` 和端口
> 3. 打开手机端重新同步，数据会从手机端同步回新电脑
> 4. 建议先备份旧电脑的 `AppData` 目录以防万一

**Q: 同步会消耗多少电量/流量？**
> 电量消耗很小，后台传输数据量不大。流量方面，首次同步消耗较多（取决于消息和附件数量），日常增量同步通常只有几十 KB 到几 MB。

**Q: 我不想同步某些内容可以吗？**
> 目前不支持选择性同步。同步范围是全局的（全部智能体、群组、消息）。如果不需要同步，关闭分布式服务器即可。

## 故障排查速查表

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 手机端完全连不上 | 桌面端分布式服务器未开启 | 开启后重启客户端 |
| 连接被拒绝 | 索引扫描未完成 | 等待 1~3 秒，看日志出现「同步总线已启动」再试 |
| 提示「Unauthorized」 | Token 不一致 | 检查两边 Token 是否完全相同 |
| 同步到一半断开 | 网络不稳定或防火墙拦截 | 检查 WiFi 稳定性，放行 5975 端口 |
| 消息两边不一致 | 某一边在同步期间又修改了内容 | 手动再同步一次 |
| 附件下载失败 | 桌面端附件文件被删除或移动 | 检查 `AppData/UserData/attachments/` 目录 |
