# ContextFoldingV2 - 上下文语义折叠 V2

## 1. 插件概述

`ContextFoldingV2` 是 VCP 框架中的高级消息预处理器（`messagePreprocessor`）。该插件在 Agent 与用户交互时，自动介入消息流管线。基于文本向量嵌入（Embedding）与余弦相似度计算，对长上下文对话历史中“距离较远、且与当前用户意图相关性较低”的早期 AI 历史回复进行智能压缩与语义摘要折叠（替换为形如 `[VCP上下文语义折叠-本层摘要: ...]` 的单行高密度描述）。

### 核心收益
- **大幅节省 Token 预算**：将冗长的前文 AI 输出折叠为精炼摘要，上下文体积削减 40%–70%。
- **保留核心记忆与连贯性**：折叠只针对低相关度的历史回复，高相关上下文以及最近的对话完全保留。
- **动态 K 公式与热调控**：结合动态阈值、长短期记忆加权（`rag_params.json`），自动调整折叠灵敏度。
- **无感运行**：无需智能体主动调用工具，由 VCP 引擎在提示词预处理阶段自动完成。

---

## 2. 插件形态与架构分类

- **插件类型**：`messagePreprocessor`（系统级消息预处理器）
- **通信协议**：`direct`（直接内存桥接，依赖 `contextBridge`）
- **调用命令**：无直接工具调用命令（`invocationCommands: []`）。智能体不需要亦不能通过 `<<<[TOOL_REQUEST]>>>` 调用此插件，其生命周期由提示词占位符驱动。

---

## 3. 激活与提示词配置规范

在角色系统提示词（System Prompt）或世界设定中引入激活占位符即可启用折叠逻辑：

### 3.1 默认激活语法
```text
{{VarSystemPrompt}}

<!-- 激活上下文语义折叠，使用默认相似度阈值 -->
[[ContextFoldingV2]]
```

### 3.2 自定义阈值激活语法
可追加浮点数参数精确控制触发折叠的语义相似度阈值（值域通常为 `0.3` 至 `0.7`）：
```text
{{VarSystemPrompt}}

<!-- 强制设置折叠阈值为 0.60（高于此相似度保留原文，低于此相似度折叠） -->
[[ContextFoldingV2:0.60]]
```

### 3.3 兼容占位符格式
亦支持经典双大括号语法（在未被宏替换提前消耗的场景）：
```text
{{ContextFoldingV2}}
或
{{ContextFoldingV2:0.55}}
```

---

## 4. 折叠效果示例

当折叠触发时，历史上下文中的非核心回复将被自动改写为：
```text
[VCP上下文语义折叠-本层摘要: 助手详细解释了双向链表的删除节点逻辑，并提供了 C++ 和 Python 的实现代码片段。]
```
最新轮次的对话（由 `FOLDING_MIN_DEPTH` 保护，默认至少保留最近 3 轮）将始终保持原始内容完整无损。

---

## 5. 核心配置与热调参数

### 5.1 环境变量配置 (`config.env`)
- `FOLDING_SUMMARY_MODEL`：生成折叠摘要的快速模型（默认 `gemini-2.0-flash-lite`）。
- `FOLDING_MIN_DEPTH`：最低折叠触发深度（默认 `3`，最新 3 层绝对不折叠）。
- `FOLDING_SIMILARITY_LOW`：相似度下限（默认 `0.3`）。
- `FOLDING_SIMILARITY_HIGH`：相似度上限（默认 `0.5`）。
- `API_URL` / `API_Key`：向量与摘要模型请求网关。

### 5.2 热调配置文件 (`rag_params.json`)
插件内置文件监视器（`chokidar`），修改此文件无需重启 VCP 服务：
- `thresholdBase`：基准相似度阈值（默认 `0.50`）。
- `thresholdRange`：动态阈值浮动范围（`[0.40, 0.60]`）。
- `contextWeights`：用户与助手上下文权重比例（默认 `[0.7, 0.3]`）。
